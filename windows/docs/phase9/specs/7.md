# #7 勤務表: 違反の種別フィルタ（E7, 6 分類・件数チップ・集中モード）

原本: `VioBuckets.kt`（3.382.0、Compose 非依存）、`MagiScheduleViews.kt` `ViolationFilterBar`/`ViolationBucketChips`/`visibleCellVio`/`vioBucketLocCounts`。

- 分類: 人員(covU/covO)・希望(pref)・連勤(c3/c3n/c3m/c3mn)・回数(low/high/apt/c2)・群ルール(groupViol/c41/c42/c41s/c42s)・窓(c1)。
  fair/weekly は場所を持たないので対象外＝常に表示。分類表と MirrorKeys.All の一致をテストで固定。
- バー（違反ゼロなら非表示）: 「違反フィルタ（種別）・要確認 Nか所」（N＝セル違反＋被覆違反＋回数違反の件数）、
  全 ON でないときだけ「すべて表示」、「集中」トグル、6 個の件数付きトグル（0 件は淡色、トグルは可能）。初期は全 ON。
- 適用先: セル枠（同セルに複数族があれば表示中の最重族で描く）・職員別/日別集計の枠・ナビバーの違反日。
- 集中モード: 違反も未反映希望も注目もないセルを淡色（不透明度 0.35）に沈める。非表示にはしない。
- VM: `VioBuckets` を `MagiApp.ViewModels` に追加（UI 非依存）。エンジン不変。
