# #9 勤務表: 土日・祝日の色分け（祝日データは外部ファイル）

原本: `JapanHolidays.kt`（assets/japan_holidays.json、2026〜2036、`tools/generate_japan_holidays.py` が生成）、`MagiScheduleViews.kt` `DayHeader`（3.441.0 祝日色）。

- 日ヘッダ: 日番号＋曜日（月〜日）。祝日と日曜＝赤の淡い地（α≈0.14）と赤文字、土曜＝青の淡い地と青文字（祝日は曜日を問わず日曜と同じ扱い）。
- 今日＝濃緑（tertiary）の太字で示し、地色は重ねない（混同回避）。祝日名は画面に文字で出さず（列幅の都合）読み上げ用に＝WinUI ではツールチップ。
- データ: `Assets/japan_holidays.json` を Android から複製（同一ファイル）。読めなければ祝日なし扱い（安全側）。開始日が解析できなければ番号のみ。
- 「▼N」（人員不足の日ヘッダ表示）は Android では `ui.v6.dayRisks` 由来＝WinUI 未配線。#10（不足サマリー）で扱う（blockers に気づき）。
- VM 変更なし。
