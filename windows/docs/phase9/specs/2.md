# #2 ホーム: 処方箋カード（次の一手・解消度）＋AIの解決提案

原本: `MagiDashboardCards.kt` `OperatorNextActionCard`（3.480.0 リデザイン／3.483.0 H-1〜H-5）、`SmartActionCard`（3.480.0）、
解消度＝`MagiViewModel` の満足度（必須が残る間は最大 55%。C# `Diagnostics.cs` に同じ式あり）。

- 状態→表示（実行中は見出し・解消度なし。進捗行は #3）:
  - 未作成: 探索バッジ（青）・「② ボタンひとつで、勤務表を作ります。」・大「勤務表をつくる」・補助「下書きをつくる（希望と期間の制約を先に埋める）」
  - 必須0: 完成バッジ（緑）・「③ できました！ そのまま配れます。」・大「印刷・書き出し」・補助「中身を見る」
  - 全て充足不可: 狩猟バッジ（橙）・赤容器・「このデータでは、ここは埋められません。（例：日）」・大「データを見直す」・補助「未充足のまま書き出す」
  - それ以外: 狩猟バッジ・黄容器・「もう少しです。◯日 が人手不足です。／必須違反が N件 残っています。」・大「なおすのを手伝って」（不足枠がある時だけ）
- 解消度行「解消度：N%（必須 残りM件／残りD日／必須は解消・調整 M件／解消済み）」＋バー。結果ありなら「ⓘ 解消度の意味」折りたたみ（文言不変）。
- 結果ありなら常設リンク「下書きから作り直す（今の結果は「元に戻す」で戻せます）」→ GenerateSmartInitial。
- AIの解決提案: 必須>0 かつ結果ありの時だけ。盤面ごとに 1 回自動で FindFixSuggestions。先頭候補＝種別チップ＋ラベル＋「違反 −N（族 −n・…）」＋「この手を適用（推奨）」＋「ほかに N 案あります」。
- WinUI: 「初期解生成」ボタンを撤去（カード内の導線と重複）。書き出しは設定タブの `ExportCsvAsync` へ委譲（`MainWindow.ExportScheduleCsvAsync`）。
  タブ遷移は `MainWindow.SelectTab`。警告色トークン `MagiWarnContainer`/`MagiOnWarnContainer` と On*Container ブラシを `MagiTheme.xaml` に追加（Kotlin の magiWarnColors 明側）。
