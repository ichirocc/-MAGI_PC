# #11 勤務表: 集計セルの内訳ダイアログ（現在/下限/上限/目標・直し方・希望取消）

原本: `MagiScheduleViews.kt` `TallyCard` の `TallyDetailUi`／`staffViolDetail`／`dayViolDetail`（3.492.0 希望取消）。

- 職員別セル（回数違反があるとき）: タイトル「名前 ・ 記号」、「現在 N回」＋種別ごとに「下限 L回 → M回 不足」「上限 H回 → M回 超過」
  「目標 A回 → M回 不足/超過」。「直し方を探す」→ `FindFixSuggestions(i, k)` で分析タブへ。
- 日別セル: 過剰（covO）は「現在 N人」「適正 H人 → M人 過剰」＋「希望で固定: 名前・名前（…取り消さない限り過剰は残ります）」と
  在勤者ごとの「◯◯ の希望を取り消す」（実行中は無効、Undo 可）。「直し方を探す」→ `FindFixSuggestions(null, k)`。
  不足（covU）は WinUI 既存の候補フライアウト（動かせる人を 1 タップで割当）を維持＝Android のダイアログより直接的な導線。
- VM 変更なし（`StaffCellLimits`/`NeedCellLimits`/`RemoveWish`/`FindFixSuggestions` は既存）。`ScheduleView` は分析タブへの遷移を MainWindow から受け取る。
