# #13 編集: 必要人数の日別例外カレンダー（複数日一括）

原本: `NeedDayEditor.kt` `NeedMonthGrid`（日曜始まりの月グリッド、各日にその日の必要人数「—／n／a–b」、個別設定は太字＋●、選択は✓）、
`NeedApplyPanel`（「N日選択中: M/D(曜)、…ほかK日」、最低人数・上限人数（空＝既定）、順序矛盾は警告、「N日に適用」「選択した日を未設定に戻す」「キャンセル」）。

- シフトを ComboBox で選ぶ（Android はセレクタ）。選択日はシフトを変えると解除。
- 適用＝選択日すべてに同じ最低/上限を書く（空欄側はその日の既定へ）。1 回の Undo で戻る（希望の一括と同じ設計）。
- 登録済み一覧（1 件ずつ削除）は WinUI 既存の `NeedDayListHost` をそのまま残す（Android の `NeedDayCard` 相当）。
- VM: `SetNeedDaysForDays(k, days, p1, p2)`／`ClearNeedDaysForDays(k, days)` を追加（テスト 2 件）。表示は `NeedCellLimits`/`NeedDayOverrides` の既存 API。
