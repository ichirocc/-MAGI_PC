# #12 編集: 職員×シフトの回数マトリクス（担当可否・目標・上下限・実績, 3.477.0）

原本: `StaffShiftMatrix.kt` `StaffShiftMatrixCard`／`matrixCell`／`StaffShiftCellSheet`／`AptStepperRow`。

- 見出し「回数マトリクス（職員 × シフト：月に何回か）」＋説明。目標合計が容量を超えるシフトがあれば赤バナー
  「⚠ 記号：目標の合計N回 ＞ 休める日数の上限/必要人数の合計M回（K回ぶんは必ず届きません）」。「目標を全リセット」（確認つき）。
- 行＝職員（群記号）、列＝シフト記号。セル: 担当不可「—」（淡色・無効）／不足「▼N」（下限割れ＝赤濃・太字、目標未達＝赤薄。休は橙薄）／
  超過「▲N」（上限超過＝橙濃・太字、目標超過＝橙薄）／その他の回数違反「△N」／通常「N」（上下限があれば枠線＋副文「L〜H／=N」、目標があれば「目標A」）。
- セルタップ→ダイアログ「名前 ・ 記号」: 現在N回と状態文、群の目標ステッパー（−/＋、同じ群の全員に適用、上下限で調整されている注記）、
  個人の下限・上限（順序矛盾は警告し適用不可）、「上限をNに引き上げて解決」/「下限をNに下げて解決」、「上下限を解除」、「この上下限を適用」。
- 担当可否の編集はここでは行わない（年間マスターの群×シフトマトリクスが唯一の編集口）。個人単位の目標上書きは作らない（grilling 確定）。
- VM: `RestShiftIndex()` を追加（テスト 1 件）。他は既存 API（`Ws1`/`StaffCellLimits`/`AptBalances`/`Ws1SetGroupApt`/`Ws1ResetGroupApt`/`SetStaffRange`/`RemoveStaffRange`）。
