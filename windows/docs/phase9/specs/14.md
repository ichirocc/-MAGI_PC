# #14 編集: 希望シフトのカレンダー（複数日一括・移動の意味論）

原本: `WishEditor.kt` `WishCard`／`WishMonthGrid`／`WishApplyPanel`／`ShiftButtonGrid`。

- WinUI には職員選択＋月グリッド＋複数日選択＋一括適用（`SetWishesForDays`/`ClearWishesForDays`）が既にあり、差分だけ実装:
  - 登録済みの希望はシフト色のチップ（色＋記号）、選択日は「d ✓」太字＋主色枠。
  - 適用パネル: 「N日選択中: M/D(曜)、…ほかK日」。適用先は担当可能シフトの色つき大ボタン（4 列）、担当外は「その他（担当外シフト）」を開くと ⚠ つきで並び、
    選ぶと「⚠「X」はこの職員の担当外です。希望は登録できますが、配置すると違反になります。」。「N日に適用」「選択した日を未設定に戻す」「キャンセル」。
- 「移動」の意味論＝既に希望がある日を選んで別シフトを適用すれば上書き（`SetWishesForDays` がキーごとに置換）。未設定に戻すは選択日の希望を削除。Android と同じ。
- 「全職員を見る」（全員の希望チップ一覧）は WinUI 既存の登録済み一覧（`WishListHost`）が担う。VM 変更なし。
