# #6 勤務表: 週送り・違反ジャンプの下固定バー＋行列クロスハイライト

原本: `MagiScheduleViews.kt` `ScheduleNavBar`/`ScheduleNavState`（3.481.0, 3.483.0 S-1/S-3）、`mondayWeeks`、クロスハイライト（3.444.0）。

- バー（グリッドの下・スクロール位置に関係なく常に見える）: 左「◀週」「週▶」／中央ラベル／右「◀違反」「違反▶」。
  週が 1 つ以下かつ違反日 0 なら非表示。週ボタンは週が 2 つ以上、違反ボタンは違反日があるときだけ。
- 週＝月曜始まりで分割（開始日の曜日から）。現在週＝左端に見えている日から導出（自由スクロールにも追従）。
  ラベル「M月 第w/n週」（週初日の月）＋「違反 d/D日」または巡回中「違反日 i/d」。区切り「 ・ 」。
- 週送り＝その週の初日の列へ横スクロール（列は隠さない）。違反ナビ＝違反のある日を前後に巡回（末尾→先頭へ回る）、
  ジャンプ先の日ヘッダを主色の太枠で約 2.5 秒強調（FocusCell(-1, day) の番兵）。
- 違反日＝セル違反（"i,j"）と被覆違反（"k,j"）の日の和集合。Android は種別フィルタ通過分のみ＝WinUI は #7 まで全種別。
- クロスハイライト＝セルをタップすると、その行の職員名（淡い主色地）と列の日付（主色太枠）を約 2.5 秒強調。セルの違反枠は変えない。
- VM 変更なし。
