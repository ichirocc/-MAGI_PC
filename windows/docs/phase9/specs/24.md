# #24 ホーム: 「なおし方を見る」（不足セルの候補ピッカー）

原本: `MagiDashboardCards.kt` `GuidedFixDialog`（3.401.0 の矛盾修正・3.475.0 の連打ガード・3.480.0 のボタン一本化・3.642.0 の件数表示・玉突き・着地）。エンジン側の根拠は `V6PortAnalyzer`（`chainVerified`・`forbidCount`・`chainFixSuggestion`）。

状態: 3.642.0 同期で実装済み。対象枠と着地先の判断は `MagiApp.ViewModels/GuidedFix.cs`（`GuidedFixRules`・`GuidedFixPlan`・`EditLanding`）に 1 か所で置き、ホームとダイアログが同じ関数を使う。玉突きの適用は `MagiViewModel.Editing.cs` の `ApplyShortageChainFix`。ViewModels・ViewModels.Tests は本機でビルド成功（テストは未実行）。WinUI は本機でコンパイルできないため CI で確認する。

- 対象枠（`GuidedFixRules.GuidedFixTarget`）＝Fixable かつ miss>0 かつ BlockedNow でない最初の枠。ホームの大ボタン「なおし方を見る」と見出し（「M/D が人員不足です。」）は、この枠の日を出す。
- 大ボタン→ ContentDialog。見出しは「なおすのを手伝います」（残りが無ければ「直し終わりました！」）。下部ボタンは「閉じる」のみ（「再作成」は下部バーに一本化）。
  - 対象あり・候補あり: 「M/D の「X」が N人 足りません。」「この日に動かせる人が N人います。だれかを「X」に入れますか？」。先頭 8 名（`GuidedFixRules.GuidedFixPreview`）を大ボタン「名前（休み） を「X」に入れる」で出し、押すと `SetCell`。8 名を超えるときは「すべて表示（ほか N 人）」で全員を出し、「一部だけ表示」で戻す（開閉は枠ごと。枠が変わると閉じる）。「入れたら「元に戻す」でいつでも取り消せます。」
  - 対象あり・候補 0・玉突きあり（`ChainVerified`）: 「だれか1人を動かすだけでは埋まりません。複数人の入れ替えで埋められます。」＋「複数人の入れ替えを使う（元に戻せます）」。押すとダイアログを閉じ、`ApplyShortageChainFix(日, シフト, "（玉突き）M/D の「X」を複数人の入替で埋める")` を呼ぶ。適用は `ApplyFixSuggestion` と同じく盤面の指紋照合・`FixApplyGate`・元に戻すを通る。
  - 対象あり・候補 0・玉突きなし: 枠の `Reason` をエラー色で出し、着地ボタン。
  - 対象なし・Infeasible あり: 「これ以上は自動で埋められません。」＋最大 4 件の理由＋「人を増やすか…」＋着地ボタン（先頭の Infeasible 枠）。
  - 対象なし・BlockedNow あり: 「いまの希望・担当のままでは埋められない日が残っています。」＋最大 4 件＋「再作成しても…」＋着地ボタン（着地先のある最初の枠。無ければ編集タブの先頭）。
  - 何も残っていない: 「人員不足の日はなくなりました。仕上げに再作成すると全体が整います。」
- 着地（`LandingFor`→`LandingButtonLabel`）: 希望で固定された本人がいる→「希望を見直す」（月次条件）／Infeasible→「担当を見直す」（年間マスター）／BlockedNow かつ禁止の並び（`ForbidCount`>0）→「禁止の並びを見直す」（年間マスター）／その他は「データを見直す」（編集タブの先頭）。`GoEditLanding` は null なら `SelectTab("edit")`、それ以外は `OpenEditDoor(scope)`（0＝月次条件、2＝年間マスター）。着地ボタンは押すとダイアログを閉じてから移る。
  - 2026-10-08 の追加（af52ce0・2da6f61）: 希望の職員の事前選択（`EditView.SelectWishStaff`）と、年間マスター内の節（`yr_ws1`→シフト一覧・`yr_cons`→制約一覧、`EditView.ScrollToSection`）への移動に対応。
- ホームの「データを見直す」（希望固定の段の補助ボタン、Infeasible の段の大ボタン）も同じ `GoEditLanding` へ送る。原因が分からない段は編集タブの先頭。
- 1 回押したら再検査が追いつくまで全候補を無効化（`GuidedFixFlow`）。開いている間は CoverageDiag/Schedule の変化で中身を組み直す（次の枠へ進む）。
