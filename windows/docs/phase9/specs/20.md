# #20 分析: C1 頭打ち診断・回数固定の影響（表示の突き合わせ）

原本: `MagiDashboardCards.kt` `C1PlateauCard`（3.325.0〜3.480.0）／`PinFixedImpactCard`（3.325.0 で分離、3.326.0 で対象別の緩めボタン）。
WinUI には「回数の固定で止まった手」節（±1 一括ボタン）だけがあり、c1 の理由カードは無かった。

- **期間の制約がなぜ直せなかったか**（`UiState.C1Plateau`）: `CauseUnknown` なら見出し「（原因未確定）」＋「残り N 件。…記録が残っていません」だけ
  （理由を語らない）。観測があれば上位 6 件を「職員 シフト（決まり）」＋原因チップ（回数固定で却下=赤／他とのトレードオフ=青／この直し方では候補なし=青）
  ＋ `RecommendedAction`（族名は BreakdownLabels）で。箱色は回数固定=エラー色、他=第二色。詳しい説明（数え方の注記と却下件数の内訳）は既定で畳む。
  6 件超は「ほか N 件（詳細はログ出力を参照）」。回数固定が 1 件以上なら「個人の回数を見直す」（編集タブへ）。
- **回数の固定が計算に与えた影響**（`ObservedPinBlockedAttempts` > 0 のときだけ）: 「…少なくとも N 回ありました。これらは他の条件では採用できる手でした。」
  計測範囲の注記 2 行は既定で畳む。「止めていた回数固定」上位 5 件＝「職員 シフト：K回に固定（A回の試行を止めました）」＋
  「下限を1下げる（K-1〜K）」（K>0 のときだけ）／「上限を1上げる（K〜K+1）」＝`RelaxStaffRangePin` を片側 1 段ずつ（旧「±1 緩める」は両側同時だった）。
  5 件超は「ほか N 件」。末尾に「押すと設定が変わります。「元に戻す」で戻せます。…」と「個人の回数を見直す」。
- 実行中はボタン無効。VM 変更なし（表示のみ）。
