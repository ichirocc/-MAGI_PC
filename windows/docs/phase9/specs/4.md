# #4 ホーム: コパイロット（助言と導線）

原本: `MagiDashboardCards.kt` `CopilotCard(ui, onGoEdit, onSoftPolish)`。

- 表示条件: 実現できない希望>0 ／ copilotHint あり ／ （研磨の限界 かつ 実行中でない）のいずれか。無ければ非表示。
- 実現できない希望（赤容器）: 「⚠ 実現できない希望が N 件（担当外シフトなど）。配布前に見直しを。」＋「希望シフトを編集」→ 編集タブ。
- 助言（secondary 容器）: 「💡 {hint}」＋「編集タブで見直す」→ 編集タブ。
- 研磨の限界（tertiary 容器）: 「✓ 必須は満たしています。残りの調整は自動で減らせます（必須は壊しません）。」＋「自動で整える」→ RunSoftPolish ／「手修正」→ 編集タブ。
- WinUI: 分析タブには 3 件の文言表示が既にある（`AnalysisView` HintText）。ホームの単独「仕上げ最適化」ボタンは Android と同じくカード内へ統合。VM 変更なし。
