# #8 勤務表: 職員名検索（行強調）＋凡例の折りたたみ

原本: `MagiScheduleViews.kt` `SearchLegendBar`（既定=閉）、`ViolationLegend`、`ShiftColorLegend`、名前列の検索強調（`MagiFlatGrid`）。

- 見出し行「検索・凡例（検索中: q）  開く ▸／閉じる ▾」をタップで開閉。閉じているときも検索語は効き続ける（見出しに表示）。
- 検索: 「職員名で検索（該当行を強調）」＋「消す」。一致（大文字小文字無視の部分一致）した職員名を青太字。行は隠さない。
- 違反の凡例（セル違反があるときだけ）: Android は形状符号（実線/破線/角）だが WinUI の違反枠は色の実線のみなので
  「赤枠＝絶対NG／橙枠＝できれば直す／桃ドット＝希望が未反映／緑ドット＝希望が反映済み」（色は設定の違反色に追従）。
- シフトの色: 記号チップ（高さ32・最小幅48・角丸6、グリッドと同じ色）。横スクロール。
- VM 変更なし。
