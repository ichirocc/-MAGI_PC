# #5 データ無し時の導線（空状態・セットアップ案内）

原本: `MagiApp.kt` `EmptyStateCard(onOpen, onSample, onNew)`（ホーム、未読込時）、`MagiSetupCards.kt` `SetupGuideCard`（編集タブ）。

- 空状態（未読込かつ実行中でない）: アイコン＋「勤務表データを開きましょう」＋説明＋
  「データを開く」（JSON ピッカー）／「サンプルで試す」（同梱フィクスチャ）／「新規につくる（空から）」（InitBlankState → 編集タブの年間マスター）。
  Android は未読込なので確認ダイアログ無し（失うものが無い）。
- セットアップ案内（編集タブ）: 件数行（希望・必要人数の例外・職員）は WinUI に既存。「次の一手: …」（職員/シフト0→基本情報、希望0→希望シフト、
  それ以外→準備OK）を差分として追加。Android 3.482.0 の「画面下の『勤務表をつくる』」は WinUI にフッターが無いため「ホームの」に置換。
- WinUI: 通常は起動時にフィクスチャが自動で入るため空状態は読込失敗時の導線。VM 変更なし。
